# 5.21 循环系统：抗高血压药 Antihypertensive Agents

授课教师：温克
主题：高血压的药物治疗

---

## 一、课程导入：高血压现状与本节学习目标

老师从上一周赵老师讲过的高血压病理内容接着往下讲，本节重点是**高血压的药物治疗**，即抗高血压药 **antihypertensive agents**。

### 1. 我国高血压流行情况

高血压在我国非常常见，尤其在北方人群，如东北、华北地区，患病人数很多。

目前我国仍主要采用 **140/90 mmHg** 作为高血压诊断标准。按这一标准，我国高血压患者约 **2.45 亿**。

老师提到，前几年曾有讨论说是否将诊断标准改为 **130/80 mmHg**。如果采用这个标准，我国高血压患者数量可能会接近 **4.5～4.9 亿**。有些欧美国家确实采用更低的诊断标准，但我国基于本国人群特点和实际情况，目前仍保留原标准。

【复习 / 临床背景】
高血压标准不是简单“国外更好”或“国内更好”，而是要结合当地人群流行病学特点、并发症谱、医疗资源和治疗策略来判断。

### 2. 世界高血压日与血压测量

每年 **5 月 17 日** 是世界高血压日 **World Hypertension Day**。五月也被称为高血压测量月 **May Measurement Month, MMM**。

【学习建议】
老师建议同学们可以自己测血压。不同时间段、不同运动状态、不同精神状态下，血压值可能不同。因此，不能因为某一次测量正常，就认为自己完全安全。高血压诊断和管理需要多次、规范、连续监测。

### 3. 本节课学习内容

本节课主要围绕三个问题展开：

1. **高血压药物分类**
   药理学每章都要先抓住“分类”，分类非常重要。
2. **一线降压药物**
   结合目前高血压用药现状，重点掌握最常用、最重要的一线降压药。
3. **其他降压药特点与合理应用原则**
   其他药物不要求逐个死背，但要知道基本靶点、特点、适应证和为什么不常作为首选。

## 二、高血压类型、分级与我国特点

### 1. 原发性高血压 Primary Hypertension

多数高血压属于**原发性高血压** **primary hypertension**。

原发性高血压的真正病因目前尚未完全明确。虽然实验研究中会提出很多机制，但从临床药物治疗角度看，仍很难做到真正意义上的“对因治疗”。因此，目前治疗主要还是**对症治疗**，即控制血压、降低靶器官损伤和并发症风险。

### 2. 我国高血压分级为什么保留三级

老师强调，中外高血压分级存在差异。欧美部分指南可能主要分为一级、二级，而我国仍保留三级。

原因是我国有相当一部分高血压患者血压非常高，尤其是 **≥180 mmHg** 的重度高血压患者比例不可忽视。这类患者脑血管意外 **stroke / cerebrovascular accident** 风险很高。

【临床关联】
老师提到自己老家在东北，那边高血压导致的脑血管意外发生率非常高。因此我国保留高血压三级分级，有其流行病学和临床治疗上的必要性。

### 3. 不同人群治疗策略不同

我国高血压患者中，脑血管意外风险较高的人群较多，因此某些情况下，药物选择会更偏向能有效扩张血管、降低脑血管事件风险的药物，比如钙通道阻滞药 **calcium channel blockers, CCBs**。

【举例】
对于北方高盐饮食人群，低盐饮食非常重要；而某些南方同学本身饮食盐摄入较低，低盐干预的意义可能没有北方人群那么突出。治疗策略应结合患者具体生活方式和危险因素。

## 三、高血压危险因素与靶器官损害

### 1. 高血压不能只看血压数值

高血压和心衰一样，不能只看一个症状或一个指标，而要综合评估。

需要同时看：

1. 血压水平
   例如 140、160、180、220 mmHg 等。
2. 危险因素 **risk factors**
   如果危险因素很多，即使血压只是正常高值，也可能属于高危甚至很高危患者。
3. 靶器官损害情况
   如心、脑、肾、视网膜等。

【临床关联】
有些人血压只是“正常高值”，但因为危险因素很多，在偶然情况下发生脑血管意外，问题并不单纯在血压数值，而在整体心血管风险。

### 2. 常见危险因素

老师提到的危险因素包括：

1. “三高”相关因素
   高血糖、高血脂、高血压本身，以及肥胖。
2. 肥胖 **obesity**
   肥胖是高血压重要危险因素。
3. 高同型半胱氨酸血症
   我国部分人群叶酸摄入不足，血中同型半胱氨酸 **homocysteine** 水平升高，可形成所谓 **H 型高血压**。
4. 药物因素
   一些药物长期使用可能增加血压或心血管风险。

### 3. 药物相关危险因素

【易错 / 临床关联】
很多人认为非处方药 **OTC drugs** 很安全，但长期使用某些药物也可能影响血压和心血管风险。

老师举了几类药：

1. 解热镇痛抗炎药 **NSAIDs / antipyretic analgesic anti-inflammatory drugs**
   长期使用某些镇痛药，可能增加心血管风险。
2. 对乙酰氨基酚 **acetaminophen / paracetamol**
   如果长期、频繁服用，也可能成为血压升高的危险因素。
3. 抗抑郁药 **antidepressants**
   抑郁症与单胺类递质水平降低有关，许多抗抑郁药会增加去甲肾上腺素 **norepinephrine, NE**、多巴胺 **dopamine, DA** 等单胺类物质水平，可能间接升高血压。
4. 甘草类制剂 **licorice preparations**
   甘草在中药中常作为佐剂，但长期服用也可能引起高血压。

### 4. 靶器官损害 Target Organ Damage

长期高血压会损伤多个靶器官 **target organs**，包括：

1. 肾脏 **kidney**
2. 心脏 **heart**
3. 脑 **brain**
4. 视网膜 **retina**

这些器官共同特点是血管非常丰富，因此高血压本质上会导致大血管、小血管等多层面的血管病变。

常见死亡或严重结局包括：

1. 心肌梗死 **myocardial infarction, MI**
2. 心力衰竭 **heart failure, HF**
3. 脑卒中 / 脑血管意外 **stroke / cerebrovascular accident**
4. 肾衰竭 **renal failure**

## 四、高血压治疗目标：控制血压与预防并发症

### 1. 控制症状：积极降压

高血压治疗第一条路是控制血压。老师把它类比为“算术题”：设定目标血压后，通过每日服药和监测，找到适合患者自己的药物和剂量。

常用目标值可以先按 **140/90 mmHg** 理解。如果患者能耐受，也可以降得更低，以获得更好的心血管保护。

### 2. 预防并发症、延长寿命

高血压药物不只是让血压数字下降，还要尽量：

1. 减少靶器官损害。
2. 降低心梗、脑卒中、心衰、肾衰等事件。
3. 降低死亡率 **mortality**。
4. 提高寿命和生活质量。

## 五、非药物治疗 Non-pharmacological Treatment

高血压治疗首先要讲非药物治疗 **non-pharmacological treatment**。

### 1. 有氧运动

保持规律有氧运动非常有效。老师提到：

每周约 **150 分钟**，每次 **30 分钟**，每周 **5 次** 的有氧运动，可帮助降低血压。

【学习建议】
不要小看跑步、运动、锻炼。有些人的降压效果甚至可接近或超过单个降压药。

### 2. 减重

减重对血压影响很大。

老师提到，如果体重下降 **10 kg**，血压可能下降约 **20 mmHg**。而通常一个降压药单药使用大约降 **10 mmHg**。

【临床关联】
减肥本身就是非常有效的降压策略，尤其适合肥胖相关高血压患者。

### 3. 限盐

普通人群每天盐摄入可按约 **10～12 g** 理解；高血压或心衰患者一般建议降到约 **5 g/day**。

【学习建议】
老师提醒，食堂饭菜盐含量往往偏高，高血压患者应主动减少盐摄入。

## 六、血压形成机制：为什么这些药能降压

老师通过血压决定因素引出药物分类。

血压有两个重要指标：

1. 收缩压 **systolic blood pressure, SBP**
2. 舒张压 **diastolic blood pressure, DBP**

### 1. 收缩压 SBP

收缩压是心脏射血时动脉压力达到的最高值。

主要影响因素是：

1. 心肌收缩力 **myocardial contractility**
2. 每搏输出量 **stroke volume**
3. 心输出量 **cardiac output, CO**

心脏射血越多、收缩力越强，SBP 越高。

### 2. 舒张压 DBP

舒张压是血管舒张时动脉压力的最低值。

主要影响因素是：

1. 血管平滑肌张力 **vascular smooth muscle tone**
2. 外周血管阻力 **peripheral vascular resistance**

血管平滑肌收缩越强，DBP 越高。

### 3. 药物治疗的基本思路

因此降压可以从几个方向入手：

1. 抑制心脏
   减少心肌收缩力、降低心率、减少心输出量。
2. 扩张血管
   降低血管平滑肌张力，减少外周阻力。
3. 减少血容量
   通过利尿、排钠减少有效循环血量。
4. 抑制交感神经
   降低心脏和血管的交感兴奋。
5. 抑制 RAAS 系统
   抑制肾素-血管紧张素-醛固酮系统 **renin-angiotensin-aldosterone system, RAAS**。

## 七、高血压发生相关系统：应激、遗传、神经、肾脏、内分泌

老师继续说明高血压背后的多个系统因素。

### 1. 应激因素 Stress

精神紧张、长期压力、应激状态可导致血压升高。

【举例】
老师提到自己曾经属于舒张压偏高型，收缩压约 130 mmHg，但舒张压接近 100 mmHg，脉压差小。主要原因与应激处理不好有关，后来通过减肥改善。

早期被认为能治疗高血压的药物之一是镇静催眠药 **sedative-hypnotics**，因为镇静后交感活性下降，血压可下降。但长期吃镇静催眠药治疗高血压显然不合适。

### 2. 遗传因素 Genetic Factors

高血压有明显遗传倾向，但遗传因素通常无法直接改变。

目前一些研究会围绕遗传异常导致的高血压机制展开，包括高血压疫苗等方向。

### 3. 中枢神经系统 Central Nervous System

交感神经活性增高可导致高血压。年轻人交感神经兴奋性通常较高，因此年轻高血压中交感活性增高是重要机制之一。

### 4. 肾脏与容量依赖性高血压

老年人中常见容量依赖性高血压，常与水钠潴留、水肿、肾脏功能有关。

因此利尿药 **diuretics** 可以治疗高血压。

### 5. 胃肠道和饮食因素

高糖、高脂、高热量饮食可导致动脉粥样硬化 **atherosclerosis**，进而促进血压升高。

### 6. 内分泌系统 Endocrine System

肾上腺 **adrenal gland / suprarenal gland** 可分泌醛固酮 **aldosterone**。如果肾上腺肿瘤导致醛固酮异常分泌，可引起继发性高血压，如原发性醛固酮增多症 **primary aldosteronism**。

【临床关联】
有些患者所有常见高血压原因都查了，血压仍降不下来，最后发现是醛固酮增多导致。

## 八、抗高血压药分类：本节第一个核心考点

【考点】
老师强调：药物分类在药理学学习和考试中非常重要。很多选择题并不需要死背单个药物，而是通过药物类别就能判断机制。

例如看到某药是 ARB，就应知道它通过阻断血管紧张素 II 受体发挥降压作用。

### 1. 利尿药 Diuretics

作用靶点：肾脏。

适用于容量依赖性高血压。

与心衰治疗不同：

1. 心衰常用高效利尿药，如呋塞米 **furosemide**。
2. 高血压长期治疗更常用中效利尿药，如噻嗪类 **thiazide diuretics**，因为作用温和、不良反应较少。
3. 低效利尿药 / 保钾利尿药 **potassium-sparing diuretics** 可用于联合用药，或用于原发性醛固酮增多症，如螺内酯 **spironolactone**。

### 2. 钙通道阻滞药 Calcium Channel Blockers, CCBs

高血压治疗中主要使用二氢吡啶类 **dihydropyridines, DHPs**，如：

1. 硝苯地平 **nifedipine**
2. 氨氯地平 **amlodipine**
3. 非洛地平 **felodipine**
4. 尼群地平 **nitrendipine**

主要作用于血管平滑肌 **vascular smooth muscle**，扩张血管。

【临床关联】
在我国高血压治疗中，CCB 重要性较高，尤其与我国脑血管事件风险高有关。

### 3. RAAS 系统抑制药 RAAS Inhibitors

包括：

1. ACEI：血管紧张素转换酶抑制药 **angiotensin-converting enzyme inhibitors**
2. ARB：血管紧张素 II 受体阻断药 **angiotensin receptor blockers**
3. 肾素抑制药 **renin inhibitors**

高血压和心衰都存在 RAAS 活性增高，因此这类药在两章中都会出现。

### 4. 交感神经抑制药 Sympatholytic Drugs

高血压时交感神经活性增高，因此可在交感通路不同节点进行抑制：

1. 中枢性降压药 **central antihypertensive drugs**
2. 神经节阻断药 **ganglion blockers**
3. 肾上腺素受体阻断药 **adrenergic receptor blockers**

   * β 受体阻断药 **beta blockers**
   * α 受体阻断药 **alpha blockers**
   * α/β 双受体阻断药
4. 神经末梢阻滞药 **adrenergic neuron blockers**

老师强调，目前真正临床更有意义的是**肾上腺素受体阻断药**，其他很多药由于不良反应大或疗效差，已较少使用。

### 5. 血管扩张药 Vasodilators

包括：

1. 硝普钠 **sodium nitroprusside, SNP**
2. 肼屈嗪 **hydralazine**
3. 硝酸酯类 **nitrates**
4. 钾通道开放药 **potassium channel openers**

这些药也可用于心衰治疗，但因作用强、短效、反射性不良反应明显，常不作为慢性高血压一线治疗。

## 九、理想降压药特点

老师引用国际高血压协会相关理念，总结理想降压药特点。

### 1. 平稳降压

理想药物应能维持 **24 小时血压平稳**，波动小。

因此现代降压治疗强调：

1. 长效制剂 **long-acting preparations**
2. 缓释制剂 **sustained-release preparations**
3. 控释制剂 **controlled-release preparations**

作用很强但持续时间短的药物，逐渐不适合作为长期降压药。

### 2. 长期不良反应少

高血压常需长期甚至终身治疗，因此药物必须安全，不良反应少。

### 3. 保护靶器官

药物不仅要降压，还要保护心、脑、肾等靶器官。

### 4. 有临床证据支持

【学习建议 / 临床思维】
老师强调临床医学要重视证据 **evidence**。不能只相信理论、研讨、头脑风暴，而要看临床试验是否证实药物能降低发病率、死亡率、住院率，并延长寿命。

### 5. 费用可承受

我国高血压患者约 2.45 亿，用药费用必须考虑患者和医保负担。

但药价也不是越低越好，过度降价可能造成“降价死”，即厂家无法继续生产，最终患者反而不能受益。

## 十、一线降压药：ABCD

【考点】
我国常用一线降压药可概括为 **ABCD**，其中 A 有两个。

1. A：ACEI
   血管紧张素转换酶抑制药。
2. A：ARB
   血管紧张素 II 受体阻断药。
3. B：β 受体阻断药 **beta blockers**
4. C：钙通道阻滞药 **calcium channel blockers, CCBs**
5. D：利尿药 **diuretics**

不同国家一线药物略有差异。有些国家不把 β 受体阻断药列为常规一线药，但我国仍将其作为一线药之一，原因是我国不少高血压患者同时合并心律失常、心衰、心绞痛等，而 β 受体阻断药对这些疾病也有治疗作用。

【考点 / 备考建议】
老师强调本节学习目标：

1. 先掌握药物分类。
2. 重点掌握 ABCD 五类一线药物的作用机制、临床应用和主要不良反应。
3. ACEI 和 β 受体阻断药条理较清楚，可能更适合出主观题或机制题。
4. 其他药物掌握靶点、特点和为什么不首选即可。

【可能考法】
老师提到去年曾考过：
“以交感神经为靶点，治疗高血压的药物分类。”

今年不一定考同题，但可能换成：
“围绕 RAAS 系统，分析治疗高血压或心衰的药物分类。”

也可能问：
哪些药物属于对症治疗？哪些药物能明确改善预后、降低死亡率？

# 十一、第一类一线药：利尿药 Diuretics

## 1. 利尿药分类与作用部位

### 1）高效利尿药 Loop Diuretics

代表药：呋塞米 **furosemide**。

作用部位：髓袢升支粗段 **thick ascending limb of loop of Henle**。

特点：

1. 利尿作用强。
2. 更适合短期、快速处理。
3. 心衰治疗中常用。
4. 高血压常规长期治疗中不是首选。

### 2）中效利尿药 Thiazide / Thiazide-like Diuretics

代表：

1. 氢氯噻嗪 **hydrochlorothiazide**
2. 吲达帕胺 **indapamide**，商品名寿比山
3. 其他噻嗪类或噻嗪样药物

作用部位：远曲小管近端 **early distal convoluted tubule**。

特点：

1. 利尿作用温和。
2. 降压作用较平稳。
3. 不良反应相对少。
4. 是高血压长期治疗更常用的一类利尿药。

### 3）低效利尿药 / 保钾利尿药 Potassium-sparing Diuretics

代表：

1. 螺内酯 **spironolactone**
2. 氨苯蝶啶 **triamterene**
3. 阿米洛利 **amiloride**

作用部位：远曲小管末端和集合管 **late distal tubule and collecting duct**。

特点：

1. 保钾。
2. 单独用于原发性高血压时不常作为首选。
3. 可与排钾利尿药联用，减少低钾血症。
4. 螺内酯可用于原发性醛固酮增多症。

---

## 2. 高血压治疗中为什么首选中效利尿药

【易错】
心衰和高血压用利尿药的首选不同。

1. 心衰急性或明显容量负荷时，常用高效利尿药，如呋塞米。
2. 高血压是长期治疗，要求平稳、安全、不良反应少，因此常用中效利尿药。

---

## 3. 中效利尿药降压机制

### 1）早期机制：排钠利尿，降低血容量

用药初期通过肾脏排钠、利尿，减少有效循环血量 **effective circulating volume**，从而降低血压。

但快速降低血容量可诱发反射性调节，如：

1. 交感神经兴奋
2. RAAS 系统激活

### 2）长期机制：扩张血管

长期小剂量使用时，利尿药还可通过影响血管平滑肌离子环境而扩张血管。

老师介绍的主要机制：

1. 长期排钠使细胞内 Na⁺ 减少。
2. 通过 Na⁺/Ca²⁺ 交换影响细胞内 Ca²⁺。
3. 细胞内 Ca²⁺ 减少，血管平滑肌舒张。
4. 血管扩张，血压下降。

也有研究认为与钾通道、一氧化氮合酶 **nitric oxide synthase, NOS** 等机制有关。

【考点】
无论早期还是长期，利尿药降压的关键环节都是 **钠 Na⁺**。

【学习建议】
低盐饮食非常重要。若每天摄入大量盐，利尿药排出的钠还不如摄入的钠多，药物效果会明显受限。

---

## 4. 利尿药临床应用

1. 一线降压药。
2. 轻度高血压可单药使用。
3. 血压较高，如 160、180 mmHg，单药难以控制时需联合用药。
4. 中效利尿药是高血压治疗常用选择。
5. 高效利尿药主要用于：

   * 高血压危象 **hypertensive crisis**
   * 合并肾功能不全或明显容量负荷的情况

---

## 5. 利尿药不良反应

### 1）电解质紊乱

常见：

1. 低钾血症 **hypokalemia**
2. 低钠血症 **hyponatremia**
3. 水电解质紊乱 **fluid and electrolyte disturbance**

低钾可能诱发心律失常 **arrhythmia**。

### 2）代谢异常

中效利尿药长期使用可能出现：

1. 高血糖 **hyperglycemia**
2. 高血脂 **hyperlipidemia**

### 3）反射性神经内分泌激活

低血容量可导致：

1. 交感神经兴奋
2. RAAS 系统活性增高

【考点 / 联合用药逻辑】
利尿药可引起 RAAS 和交感神经反射性激活，因此常与 ACEI、ARB 或 β 受体阻断药联合。

1. 利尿药 → RAAS 激活
   ACEI / ARB 可抵消。
2. 利尿药 → 交感神经兴奋
   β 受体阻断药可抵消。
3. 利尿药 → 低钾
   ACEI / ARB 可能导致高钾，两者有时可部分抵消电解质不良反应。

---

## 6. 吲达帕胺 Indapamide

吲达帕胺 **indapamide** 是噻嗪样利尿药 **thiazide-like diuretic**，商品名“寿比山”。

特点：

1. 通过排钠利尿降压。
2. 对血脂无明显不利影响。
3. 对合并高脂血症患者可能更合适。
4. 老师提到国际高血压协会相关评价中，如果有这类药物，可优先考虑。

---

# 十二、第二类一线药：钙通道阻滞药 CCBs

## 1. CCB 在循环系统多章节反复出现

【学习建议】
CCB 是跨章节药物。心律失常、心绞痛、高血压等章节都会出现，但不同疾病使用的 CCB 类型不同，需要串起来复习。

CCB 主要靶点：

1. 血管平滑肌上的钙通道
2. 心脏上的钙通道

阻断钙通道后：

1. 血管平滑肌舒张 → 扩血管 → 降压。
2. 心脏受抑制 → 负性频率、负性肌力、负性传导。

## 2. 高血压治疗主要用二氢吡啶类 DHPs

高血压和心绞痛主要使用二氢吡啶类 **dihydropyridines, DHPs**，药名多以“地平”结尾。

代表：

1. 硝苯地平 **nifedipine**
2. 氨氯地平 **amlodipine**
3. 非洛地平 **felodipine**
4. 拉西地平 **lacidipine**
5. 尼群地平 **nitrendipine**

第一代药物硝苯地平扩血管很强，但普通片吸收快、起效快、作用时间短，不适合长期平稳控制血压。

第二代药物或长效制剂更适合 24 小时平稳降压。

## 3. DHP 类 CCB 的主要作用部位

【易错】
二氢吡啶类 CCB 主要作用于**血管平滑肌**，不是主要作用于心脏。

因为动脉系统平滑肌成分多，所以 DHP 类药物主要扩张动脉 **arterioles / arteries**，降低外周阻力。

## 4. 缓释、控释和长效制剂的意义

老师用普通片和缓释 / 控释片血药浓度曲线说明：

1. 普通片：血药浓度快速升高、快速下降。
2. 缓释制剂：吸收较慢，持续时间延长。
3. 控释制剂：更接近零级释放，在一定时间内释放固定剂量药物。

【考点】
高血压治疗强调 **24 小时平稳降压**。血压像“过山车”一样快速下降、快速升高，对靶器官损伤很大，有时比长期维持较高但相对稳定的血压更危险。

因此现代治疗更强调长效、缓释、控释制剂。

## 5. 短效 DHP 的问题

短效硝苯地平普通片可导致：

1. 血压快速下降。
2. 反射性交感神经兴奋。
3. 心率增快。
4. 心肌耗氧量增加。
5. 心肌缺血加重。

【易错】
短效 DHP 制剂一般不适合缺血性心脏病 **ischemic heart disease** 患者，因为可能加重心肌耗氧和缺血。

## 6. CCB 不良反应

多数不良反应与血管扩张有关：

1. 头痛 **headache**
2. 心悸 **palpitation**
3. 面部潮红 **flushing**
4. 眩晕 **dizziness**
5. 踝部水肿 **ankle edema**

### 踝部水肿机制

【临床关联 / 易错】
DHP 类导致的踝部水肿通常不是肾损伤导致的全身性水肿。

机制是：

1. DHP 主要扩张动脉端。
2. 静脉扩张较弱。
3. 毛细血管灌注压升高。
4. 局部液体滤出增加。
5. 出现踝部水肿。

这属于局部血流动力学改变，而不是首先考虑肾功能损伤。

## 7. 非二氢吡啶类 CCB

### 1）维拉帕米 Verapamil

心脏作用强，主要用于心律失常，尤其阵发性室上性心动过速 **paroxysmal supraventricular tachycardia, PSVT**。

### 2）地尔硫䓬 Diltiazem

作用介于二氢吡啶和维拉帕米之间，既有一定血管作用，也有心脏作用，可用于心律失常，也有降压作用。

【考试提醒】
如果是最优单选题，治疗高血压优先选二氢吡啶类。
如果是多选题问“哪些 CCB 可以治疗高血压”，维拉帕米和地尔硫䓬也有降压作用，但不是高血压首选。

# 十三、第三类一线药：ACEI

ACEI 即血管紧张素转换酶抑制药 **angiotensin-converting enzyme inhibitors**，常见药名后缀为“普利”。

## 1. 作用靶点

ACEI 的靶点是血管紧张素转换酶 **angiotensin-converting enzyme, ACE**。

ACE 不只存在于血液循环中，也存在于心肌和血管平滑肌等组织局部。

## 2. 降压机制

ACEI 通过抑制 ACE：

1. 减少血管紧张素 II **angiotensin II, Ang II** 生成。
2. 减少 Ang II 导致的血管收缩。
3. 降低醛固酮 **aldosterone** 水平。
4. 增加缓激肽 **bradykinin** 水平。
5. 扩张血管，降低血压。

## 3. 长期保护作用

ACEI 的重要意义不仅是降压，还包括对高血压并发症和靶器官损害的保护。

### 1）改善心肌肥厚和血管重构

高血压可导致心肌肥厚 **cardiac hypertrophy** 和血管重构 **vascular remodeling**。ACEI 通过降低 Ang II，有助于改善这些改变。

### 2）肾脏保护

ACEI 可增加肾血流，并有肾脏保护作用。

老师特别强调，与许多单纯扩血管药不同，ACEI 虽然扩血管，但不容易引起明显水钠潴留。

### 3）不明显引起反射性心率增快

多数扩血管药降压后会反射性交感兴奋、心率增快。ACEI 对交感神经影响较特殊，不会明显引起反射性心率增快。

### 4）保护血管内皮

高血压与动脉粥样硬化、血管重构、内皮损伤互相影响。ACEI 对血管内皮有保护作用。

### 5）改善胰岛素敏感性

高血压和 2 型糖尿病 **type 2 diabetes mellitus, T2DM** 有共同病理生理基础之一：胰岛素抵抗 **insulin resistance**。ACEI 可改善胰岛素敏感性。

## 4. 临床应用

ACEI 是一线降压药，可单用或联合使用。

对于严重高血压，常需要联合用药。

## 5. ACEI 不良反应与禁忌证

### 1）刺激性干咳 Dry Cough

机制与缓激肽 **bradykinin** 增多有关。

### 2）血管性水肿 Angioedema

同样与缓激肽相关。

### 3）首剂现象 First-dose Phenomenon

【可能考名词解释】
首剂现象 **first-dose phenomenon** 指第一次使用某些扩血管降压药后，患者可能出现体位性低血压 **orthostatic hypotension**、头晕甚至晕厥。

常见诱因：

1. 第一次服药。
2. 服药后由坐位、卧位变为立位。
3. 血管扩张后血液不能及时回流。

预防：

1. 初始小剂量。
2. 逐渐加量。
3. 可睡前服药，减少体位改变导致的风险。

### 4）高钾血症 Hyperkalemia

ACEI 可使醛固酮下降，导致血钾升高。

高风险情况：

1. 肾功能障碍。
2. 与保钾利尿药合用。
3. 原本存在高钾风险的患者。

### 5）妊娠禁忌

ACEI 有致畸胎作用 **teratogenicity**，妊娠期高血压患者禁用。

【考点】
妊娠期高血压 **gestational hypertension / pregnancy-induced hypertension** 用药选择很麻烦，ACEI 和 ARB 是明确禁忌。

### 6）双侧肾动脉狭窄禁忌

双侧肾动脉狭窄 **bilateral renal artery stenosis** 患者使用 ACEI 可能加重肾功能损伤，导致尿量减少，因此禁用。

## 6. 常见 ACEI

1. 卡托普利 **captopril**
   第一代，作用强但时间较短。
2. 依那普利 **enalapril**
3. 贝那普利 **benazepril**
4. 福辛普利 **fosinopril**

后几类更适合长期应用。

# 十四、第四类一线药：ARB

ARB 即血管紧张素 II 受体阻断药 **angiotensin receptor blockers**，常见药名后缀为“沙坦”。

## 1. 代表药

常见 ARB 很多，老师特别提到坎地沙坦 **candesartan**。

坎地沙坦特点：

1. 长效。
2. 维持时间长。
3. 谷峰比 **trough-to-peak ratio** 较高。
4. 血压控制更平稳。

## 2. ARB 与 ACEI 的区别

### 1）作用更完整

ACEI 只能阻断 ACE 途径生成的 Ang II，但不能完全阻断旁路途径生成的 Ang II。ARB 直接阻断 AT1 受体，因此作用更完整。

### 2）咳嗽和血管性水肿更少

ARB 不明显增加缓激肽，因此干咳和血管性水肿少于 ACEI。

### 3）适合 ACEI 不能耐受者

若患者不能耐受 ACEI，常可改用 ARB。

## 3. ARB 不良反应与禁忌

整体不良反应较少，但仍需注意：

1. 高钾血症。
2. 肾功能损害风险。
3. 妊娠期绝对禁用。

## 4. ACEI 与 ARB 不能联用

【重点考点】
ACEI 和 ARB 都是好药，但**绝对不推荐联合应用**。

老师用联合用药原则分析：

联合用药通常应满足：

1. 增加疗效。
2. 减少不良反应。

ACEI + ARB 的问题：

1. 两者作用于同一条 RAAS 通路，疗效并不优于合理增加单药剂量。
2. 不良反应高度重叠：

   * 高钾血症
   * 肾功能损害
   * 低血压
3. 因此指南明确禁止 ACEI 和 ARB 联合用于常规降压治疗。

【考试提醒】
可能考“ACEI 和 ARB 能否联用？为什么？”
答案：不能。因为疗效不明显增加，而高钾、肾损伤、低血压等风险增加。

# 十五、其他 RAAS 抑制策略

## 1. 直接肾素抑制药 Direct Renin Inhibitors

代表药：阿利吉仑 **aliskiren**。

理论上可直接抑制肾素 **renin**，减少 RAAS 激活。

但临床研究未显示其明显优于 ACEI / ARB，因此目前不是优先选择。

## 2. 高血压疫苗 Hypertension Vaccines

老师提到，有公司围绕 RAAS 系统不同环节研发高血压疫苗。

理论优势：

1. 高血压患者需长期每日服药。
2. 如果通过几次免疫获得长期降压效果，可能改善依从性。
3. 单独使用效果可能类似一个一线降压药，降约 10～20 mmHg。

但老师强调，临床医学看证据，目前仍需临床试验验证。

# 十六、第五类一线药：β 受体阻断药 Beta Blockers

## 1. 常用药物

高血压治疗中常用 β1 选择性阻断药：

1. 美托洛尔 **metoprolol**
2. 阿替洛尔 **atenolol**
3. 比索洛尔 **bisoprolol**

非选择性 β 阻断药如普萘洛尔 **propranolol** 更容易引起支气管哮喘等问题。

## 2. β 受体阻断药降压机制

### 1）作用于心脏 β1 受体

阻断心肌 β1 受体后：

1. 负性肌力 **negative inotropic effect**
2. 负性频率 **negative chronotropic effect**
3. 负性传导 **negative dromotropic effect**
4. 心输出量下降
5. 收缩压下降

其中对降压最重要的是降低心肌收缩力和心率。

### 2）作用于肾脏 β1 受体

肾小球旁器 **juxtaglomerular apparatus** / 近球细胞有 β1 受体，参与调控肾素分泌。

阻断后：

1. 肾素分泌减少。
2. RAAS 活性下降。
3. 血压下降。

### 3）作用于中枢

中枢心血管调节区域 β 受体被阻断可降低交感活性，但这一机制争议较大。脂溶性高的药更容易进入中枢，但脂溶性高低对整体降压效果影响并非决定性。

### 4）作用于突触前膜 β2 受体

突触前膜 β2 受体参与正反馈调控去甲肾上腺素释放。阻断后，去甲肾上腺素释放减少，外周交感作用下降。

### 5）个别药物有扩血管作用

奈必洛尔 **nebivolol** 可促进一氧化氮 **nitric oxide, NO** 或前列环素 **prostacyclin, PGI₂** 相关扩血管作用。

【易错】
这种扩血管作用是奈必洛尔等个别药物的特点，不是所有 β 受体阻断药的共同作用。

## 3. β 受体阻断药在不同指南中的地位

老师提到，不同国家对 β 受体阻断药评价不同。

1. 美国早已将其从常规一线药中弱化。
2. 欧洲指南更强调 A、C、D，但对于合并特定适应证的患者仍可用。
3. 我国指南仍将其列为一线药之一，但更强调适用人群。

## 4. 适用人群

β 受体阻断药特别适合：

1. 交感神经活性高的青壮年高血压患者。
2. 高血压合并心律失常 **arrhythmia**。
3. 高血压合并心绞痛 **angina pectoris**。
4. 高血压合并冠心病 **coronary heart disease, CHD**。
5. 高血压合并心肌梗死后状态。
6. 高血压合并心衰。
7. 主动脉瘤 **aortic aneurysm**。
8. 主动脉夹层 **aortic dissection**。
9. 快速性心律失常 **tachyarrhythmia**。

【易错】
β 受体阻断药对老年人脑血管事件预防效果相对较差，因此不是所有高血压患者都优先使用。

## 5. 反跳现象 Rebound Phenomenon

【考点】
β 受体阻断药不能突然停药。

突然停药可能导致：

1. 血压反跳性升高。
2. 心率增快。
3. 心绞痛加剧。
4. 心肌梗死风险增加。

用药原则：

1. 起始小剂量。
2. 逐渐加量。
3. 停药时逐渐减量。
4. 一般不建议随意停药。

# 十七、其他降压药：α1 受体阻断药

## 1. 代表药

1. 哌唑嗪 **prazosin**
2. 特拉唑嗪 **terazosin**
3. 多沙唑嗪 **doxazosin**

## 2. 作用机制

α1 受体位于血管平滑肌上。

激动 α1 → 血管收缩 → 血压升高。
阻断 α1 → 血管舒张 → 血压下降。

## 3. 为什么强调 α1 而不是 α2

【易错】
不能把非选择性 α 阻断药简单用于高血压。

α2 受体位于突触前膜，具有负反馈作用。激动 α2 会减少去甲肾上腺素释放；阻断 α2 则会增加去甲肾上腺素释放。

如果药物同时阻断 α1 和 α2，如酚妥拉明 **phentolamine**：

1. α1 阻断可扩血管。
2. α2 阻断使 NE 释放增加。
3. NE 可激动 β1 受体。
4. 心率增快、心脏兴奋。

因此酚妥拉明不适合常规治疗高血压。

## 4. 临床特点

α1 阻断药对血脂没有明显不利影响，但由于临床试验证据不足或结局不理想，目前已不作为一线药。

## 5. 合并前列腺增生时有优势

α1 受体也分布于前列腺和相关括约肌。老年男性常同时有：

1. 高血压
2. 良性前列腺增生 **benign prostatic hyperplasia, BPH**

因此 α1 阻断药可同时改善排尿困难和降低血压。

【临床关联】
没有高血压的前列腺增生患者使用这类药时，也可能出现血压下降甚至低血压。

## 6. 首剂现象

α1 阻断药也容易出现首剂现象 **first-dose phenomenon**，需小剂量起始、睡前服用、逐渐加量。

# 十八、α/β 双受体阻断药

## 1. 代表药

1. 拉贝洛尔 **labetalol**
2. 卡维地洛 **carvedilol**

## 2. 作用机制

同时阻断：

1. α1 受体 → 扩血管
2. β 受体 → 抑制心脏、降低心率和心输出量、抑制肾素释放

因此兼具 α1 阻断药和 β 阻断药的作用特点。

## 3. 拉贝洛尔 Labetalol

特点：

1. 可用于妊娠期高血压。
2. 有注射剂型。
3. 可用于高血压危象 **hypertensive crisis** 或高血压急症 **hypertensive emergency**。

【考点】
妊娠期 ACEI、ARB 禁用，拉贝洛尔是较重要选择之一。

## 4. 卡维地洛 Carvedilol

卡维地洛主要为口服制剂。

临床上多用于轻中度高血压，不能像注射拉贝洛尔那样快速处理高血压危象。

# 二十、中枢性降压药 Central Antihypertensive Drugs

## 1. 代表药

1. 可乐定 **clonidine**
2. 甲基多巴 **methyldopa**
3. 莫索尼定 **moxonidine**
4. 利美尼定 / 雷美尼定 **rilmenidine**

## 2. 靶点

中枢性降压药主要作用于：

1. α2 受体 **α2 adrenergic receptor**
2. 咪唑啉受体 **imidazoline receptor**

作用部位包括：

1. 延髓孤束核 **nucleus tractus solitarius, NTS**
2. 延髓腹外侧区，尤其与交感输出有关区域

激动这些受体可降低外周交感神经活性，从而降压。

## 3. 小剂量降压，大剂量或快速静注可升压

【易错】
可乐定等药物如果快速静脉推注或剂量过大，初期可能不是降压，而是升压。

原因是外周血管平滑肌上也有 α2 受体，快速高浓度时先激动外周 α2 受体，引起血管收缩 **vasoconstriction**。

小剂量时主要作用于中枢，抑制交感神经系统，表现为降压。

## 4. 不引起明显反射性心率增快

许多扩血管药降压后会反射性心率增快，但中枢性降压药直接降低交感中枢活性，因此心率增快不明显。

## 5. 为什么不常用

可乐定降压作用较强，但中枢作用导致镇静 **sedation**，长期服用影响生活质量。

可乐定还可作用于蓝斑核 **locus coeruleus**，产生镇静。

莫索尼定、利美尼定等药物镇静作用较少，但仍不是理想一线药。

## 6. 临床应用

目前属于二线药物。

曾用于：

1. 肾性高血压 **renal hypertension**
2. 合并消化性溃疡的高血压患者
   因其可减少胃肠分泌，但现在已不是重点考点。
3. 阿片类药物成瘾戒断辅助治疗
   如吗啡 **morphine**、哌替啶 **pethidine / Dolantin**、海洛因 **heroin**、芬太尼 **fentanyl** 戒断时，蓝斑核放电增加，患者烦躁、戒断反应明显。可乐定可抑制蓝斑核放电，用于缓解戒断症状。

## 7. 不良反应

1. 镇静
2. 口干
3. 水钠潴留
4. 停药反跳

# 二十一、血管扩张药 Vasodilators

老师强调，这类药不是现在高血压长期治疗的重点，因为问题较多。

主要问题：

1. 反射性交感神经兴奋
2. 反射性 RAAS 激活
3. 常需联合用药
4. 有些药作用过强或过短

## 1. 肼屈嗪 Hydralazine

主要扩张小动脉。

可用于：

1. 中重度高血压
2. 需要联合用药的情况
3. 某些心衰患者，尤其射血分数降低、心输出量低者

问题：

1. 反射性心率增快
2. RAAS 激活
3. 不适合单用

## 2. 硝普钠 Sodium Nitroprusside, SNP

【重点临床药】
硝普钠用于严重高血压急症治疗，是典型的速效、强效、短效药物。

特点：

1. 静脉泵入。
2. 约 30 秒起效。
3. 约 2 分钟达到最大降压效应。
4. 停药约 3 分钟后血压可恢复。

适应证：

1. 高血压危象 **hypertensive crisis**
2. 高血压急症 **hypertensive emergency**
3. 手术中控制性降压 **controlled hypotension**

不适合慢性轻中度高血压长期治疗，因为无法维持 24 小时平稳降压。

### 不良反应与毒性

1. 反射性交感兴奋。
2. 氰化物 / 硫氰酸盐毒性。
   硝普钠代谢可产生氰化物和硫氰酸盐 **thiocyanate**，蓄积可中毒。
3. 甲状腺功能减退风险。
   硫氰酸盐过多可抑制甲状腺滤泡细胞摄碘功能。

【临床细节】
硝普钠常需避光，用“小黑瓶”或遮光装置输注，且不能连续大量长期使用。

## 3. 钾通道开放药 Potassium Channel Openers

靶点：ATP 敏感性钾通道 **ATP-sensitive potassium channels, KATP channels**。

机制：

1. 开放 K⁺ 通道。
2. 细胞膜超极化 **hyperpolarization**。
3. 血管平滑肌抑制。
4. 血管扩张，血压下降。

代表药包括米诺地尔 **minoxidil** 等。

特点：

1. 扩血管作用强。
2. 可用于严重高血压。
3. 不适合单用。

### 米诺地尔与多毛

米诺地尔现在更常见用途是治疗男性脱发。

如果长期用于降压，常见不良反应是多毛 **hypertrichosis**，老师提到患者中出现比例很高，因此不适合长期作为常规降压药。

# 二十二、神经末梢阻滞药 Adrenergic Neuron Blockers

## 1. 代表药

1. 胍乙啶 **guanethidine**
2. 利血平 **reserpine**

## 2. 机制

### 利血平 Reserpine

抑制囊泡对去甲肾上腺素的摄取，使囊泡内神经递质逐渐减少，最终降低交感神经作用。

### 胍乙啶 Guanethidine

进入囊泡并置换去甲肾上腺素，使交感递质释放和储存受影响，最终降压。

## 3. 为什么不用

1. 胍乙啶作用太强，不适合常规应用。
2. 利血平作用较弱，且可影响中枢单胺类递质，导致抑郁，严重时有自杀倾向风险。

【易错】
降压药不能因为降压有效就用，还必须考虑长期生活质量和严重精神不良反应。

# 二十三、北京降压 0 号

老师提到我国曾有复方制剂“北京降压 0 号”。

成分包括：

1. 利血平 **reserpine**
2. 肼屈嗪 **hydralazine**

# 二十五、高血压药物应用原则

## 1. 有效治疗

首先要设定目标血压。例如目标为 **140/90 mmHg**，服药后能达到目标才叫有效治疗。

不同患者目标不同，应结合年龄、合并症、耐受性和风险分层决定。

## 2. 终身治疗

多数人为原发性高血压，需要长期甚至终身治疗。

除非生活方式明显改善，如减重、限盐、运动后血压恢复正常，否则一般“吃药比不吃药好”。

## 3. 合理剂量

高血压是长期用药，应尽量用较小剂量达到降压目的，减少不良反应。

原则：用最小有效剂量解决最大问题。

## 4. 优先选择有靶器官保护作用的药物

优先考虑 ABCD 类一线药：

1. ACEI
2. ARB
3. β 受体阻断药
4. CCB
5. 利尿药

这些药物不仅能降压，也有更多靶器官保护和预后证据。

## 5. 使用长效制剂，减少血压波动

血压波动越大，靶器官损伤越重。

因此要尽量选择：

1. 长效药物
2. 缓释药物
3. 控释药物
4. 谷峰比高的药物

## 6. 谷峰比 Trough-to-peak Ratio

谷峰比 **trough-to-peak ratio** 指药物降压作用最低谷值与最高峰值之间的比例。

例如：

1. A 药谷峰比 75%
2. B 药谷峰比 45%

虽然 B 药峰值降压可能更明显，但 A 药更平稳，更符合长期降压要求。

【考点】
降压不是“降得越猛越好”，而是越平稳越好。

坎地沙坦谷峰比较高，可达到约 80%，因此平稳降压能力较好。

## 7. 单药还是联合用药

单药通常可降低约 **10 mmHg**。

若轻度高血压，单药可解决。
若血压较高或单药不能达标，则联合用药。

联合用药可达到约 **20 mmHg** 甚至更多的降压幅度，顽固性高血压可能需要三药联用。

## 8. 联合用药原则

理想联合用药应：

1. 增强疗效。
2. 减少不良反应。
3. 作用靶点不同。
4. 不良反应可相互抵消。

优先联合示例：

1. 利尿药 + ACEI
2. 利尿药 + ARB
3. CCB + ACEI / ARB
4. β 受体阻断药 + 利尿药，视患者情况选择

【禁忌联合】
ACEI + ARB 不推荐，甚至明确禁止常规联合。

## 9. 特殊患者用药选择

### 1）合并心衰

可优先考虑：

1. ACEI
2. ARB
3. β 受体阻断药
4. 利尿药

因为这些药同时有心衰治疗意义。

### 2）合并支气管哮喘

避免非选择性 β 受体阻断药，如普萘洛尔。

β1 选择性药相对安全，但仍需谨慎。

### 3）妊娠期高血压

ACEI、ARB 禁用。
拉贝洛尔可作为重要选择之一。

### 4）合并前列腺增生

α1 受体阻断药可兼顾降压和改善排尿。

# 二十六、最后总结：按靶点重新梳理所有降压药

老师最后按作用靶点重新串了一遍。

## 1. 作用于中枢

1. 可乐定 **clonidine**
2. 甲基多巴 **methyldopa**
3. 莫索尼定 **moxonidine**
4. 利美尼定 **rilmenidine**

通过抑制中枢交感神经活性降压。

## 2. 作用于交感神经通路

包括：

1. 中枢性降压药
2. 神经节阻断药
3. 神经末梢阻滞药
4. β 受体阻断药
5. α1 受体阻断药
6. α/β 双受体阻断药

## 3. 作用于血管

主要包括：

1. CCB，最重要。
2. α1 受体阻断药。
3. 血管扩张药，如肼屈嗪、硝普钠。
4. 钾通道开放药。

其中 CCB 因长效制剂可平稳降压，所以是一线药；而肼屈嗪、硝普钠等反射性反应明显，不作为慢性高血压首选。

## 4. 作用于肾脏

主要是利尿药。

高血压治疗优先中效利尿药，而心衰治疗常用高效利尿药。

## 5. 作用于 RAAS 系统

包括：

1. ACEI
2. ARB
3. 肾素抑制药
4. 高血压疫苗研究方向

## 6. 最需要优先掌握的一线药

仍是 ABCD：

1. ACEI
2. ARB
3. β 受体阻断药
4. CCB
5. Diuretics
